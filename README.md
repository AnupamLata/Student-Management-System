# Student Management System

A web-based Student Management System developed using React, Node.js, Express.js and PostgreSQL. The application helps administrators manage student records efficiently.

## Features

- Admin Dashboard
- Add New Students
- View Student Records
- Update Student Details
- Delete Student Records
- Search Students
- Course Management
- Live Database Connectivity

## Technology Stack

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL

## Backend API

- GET /api/students
- POST /api/students
- PUT /api/students/:id
- DELETE /api/students/:id
- GET /api/health

## Deployment

Frontend and backend are deployed on separate AWS EC2 instances.
